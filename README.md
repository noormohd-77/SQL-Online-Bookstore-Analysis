# 📚 Online Bookstore – SQL Database Management & Data Analysis

## 📌 Project Overview

The **Online Bookstore SQL Project** focuses on designing, managing, and analyzing an online bookstore database using SQL.

The project involves creating relational database tables, importing datasets from CSV files, verifying data integrity, and executing basic and advanced SQL queries to extract meaningful business insights.

## 🎯 Project Objectives

- Design a structured relational database for an online bookstore.
- Create and manage Books, Customers, and Orders tables.
- Establish primary key and foreign key relationships.
- Import datasets from CSV files.
- Verify data ingestion and database integrity.
- Perform basic and advanced SQL queries.
- Analyze sales, revenue, customer purchasing behavior, and inventory.

## 🛠️ Skills & Concepts Used

- SQL (Structured Query Language)
- Relational Database Management
- Database Design
- Primary Keys & Foreign Keys
- CSV Data Import
- Data Validation
- Filtering and Sorting
- Aggregate Functions
- Joins and Grouping
- Business Data Analysis

## 🗄️ Database Structure

The project consists of three main tables:

| Table | Description |
|---|---|
| Books | Stores book information, including genre, author, price, and stock. |
| Customers | Stores customer information and location details. |
| Orders | Stores order details, quantities, and total amounts. |

## 📥 Data Import & Verification

- Created database tables with appropriate primary and foreign keys.
- Imported Books, Customers, and Orders datasets from CSV files.
- Verified data ingestion for Customers and Orders tables.

## 🔍 SQL Tasks & Analysis

### 1. Basic SQL Queries

1. Retrieve all books in the Fiction genre.
2. Find books published after 1950.
3. List all customers from Canada.
4. Retrieve orders placed in November 2023.
5. Calculate the total stock of available books.
6. Find the most expensive book.
7. Identify customers who ordered more than one quantity of a book.
8. Retrieve orders with a total amount exceeding $20.
9. List all available book genres.
10. Find the book with the lowest stock.
11. Calculate total revenue generated from all orders.

### 2. Advanced SQL Queries

1. Calculate the total number of books sold for each genre.
2. Find the average price of books in the Fantasy genre.
3. Identify customers who have placed at least two orders.
4. Find the most frequently ordered book.
5. Retrieve the top three most expensive Fantasy books.
6. Calculate the total quantity of books sold by each author.
7. Identify cities where customers who spent over $30 are located.
8. Find the customer who spent the most on orders.
9. Calculate the remaining stock after fulfilling all orders.
